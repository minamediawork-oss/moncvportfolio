# Professional Student CV Website

A modern and responsive professional CV website created with HTML and CSS for an ISPITS Agadir student.  
This project features a clean design, profile section, education, skills, projects, experience, and contact information.

## Features
- Responsive modern design
- Professional student CV layout
- Clean HTML & CSS structure
- Sidebar profile section
- Skills progress bars
- Education & experience timeline
- Mobile-friendly interface

## Technologies Used
- HTML5
- CSS3
- Google Fonts

## Preview
Professional portfolio and CV template suitable for students and personal branding.
